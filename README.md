# Minigame 1
## Devlog
Gaozan Ye, he/him

A Unity Scene is like a theater stage prepared for a performance. GameObjects are the actors and props placed on that stage, such as the player, coins, and platforms. Components give each actor or prop its appearance and abilities. A Renderer makes an object visible, a Collider defines where it can touch other objects, and a script controls its behavior. A GameObject brings these Components together, while the Scene organizes the GameObjects into a complete setting where they can interact.

In this level, “Sky Steps,” seven floating platforms form a winding, rising route. Six coins encourage the player to explore the route, and six spike traps make positioning matter. The player's movement speed is 5 instead of the original 4. The coins combine visible models, trigger colliders, and their Points tag with the player's script to increase the score. The spike objects use hazard triggers to make the player respawn and reset the collected coins. Together, these GameObjects and their Components turn the Scene into a playable platforming challenge.
